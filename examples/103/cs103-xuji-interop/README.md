# 许继 103 over 104 全操作验收工具

用库内的许继私有实现，逐项执行许继 103 模拟器包含的全部操作，校验应答并记录收发报文。

## 用法

```bash
dotnet run -- 2403              # 连接目标（许继模拟器或本库从站）
dotnet run -- 2403 --verbose    # 逐帧打印收发
```

注意：参数必须紧跟 `--` 之后，且用 `dotnet run -- <port>` 形式。
若参数丢失导致连到默认端口，用编译好的 exe 直接跑更稳妥：
`bin/Debug/net8.0/cs103-xuji-interop.exe 2403`

### 本轮修掉的缺陷

**TI=61 命令的 VSQ 取值错误**（`SettingClient.SendAsync`）

原实现走 `Iec103Client.SendPrivateAsync`，该方法固定按 `SQ=1, N=1` 组 VSQ（即 `0x81`）。
但规约表28 要求带定值项时 VSQ = 「1 个头元素 + N 个定值项」：

| 场景 | 规约 | 修复前 | 修复后 |
|---|---|---|---|
| 调定值 / 执行（无值） | `81H` | `81H` ✓ | `81H` ✓ |
| 单项预发（1 项） | `02H` | `81H` ✗ | `02H` ✓ |
| 整区返校（27 项） | `1CH` | `81H` ✗ | `1CH` ✓ |

修复方式：`SendAsync` 不再走 `SendPrivateAsync`，改为直接构造 `Asdu`，
按有无定值项分别设置 `Sq` / `Count`。

回归测试：`tests/CS103ApduFramingTests.cs` 的 `SettingCommand_VsqMatchesSpecTable`
覆盖无值 / 1 项 / 27 项三种情况。
